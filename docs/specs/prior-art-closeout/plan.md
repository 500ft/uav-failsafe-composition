## Frozen procedure

Read before write. Every new record follows the existing [day-3 rubric](../../day3-reading-rubric.md) and the record shape already in `docs/day3-reading-records.json`: `source_id`, `title`, `url`, `access`, `version`, `text_sha256_prefix`, `locator`, `aboutness`, `evidence_grade`, `finding`, `axes`, `axis_states`, `retrieved_on`. `axis_states` uses only `disclosed_or_addressed | not_found_in_inspected | not_applicable | unresolved`; anything else is rejected by `scripts/reference_coverage.py` and by `tests/test_reference_coverage.py`.

Access rules: a source counts as inspected only if its full text (or, for U3, the repository tree and the named policy/config files) was actually opened and hashed. Abstract-only, paywalled, or unreachable → `access` says so and every axis stays `unresolved`. No substitute facts.

Register rule: the successors are NOT added to `docs/source-eligibility-register.json`. That file is the day-1 set and a test pins it to exactly the day-1 IDs. Successors get reading-record IDs `S1`–`S3` (the day-1 table already uses `U` and `S` prefixes; check for collisions first) and live only in the reading records and the prior-art tables.

Regeneration rule: new reading records change two committed artifacts. Both are regenerated by their own scripts, never hand-edited: `evidence/task-day3-2026-09-09/acquisition-ledger.json` via `python scripts/acquisition_ledger.py`, and `evidence/task-2026-09-12/reference-coverage.json` via `python scripts/reference_coverage.py`. The axis table in `docs/reference-coverage-2026-09-12.md` is then re-copied from the script output, not edited by hand.

No new broad search. No new query legs. No patent database run (none reachable; say so). No spending, outreach, publication, or hardware.
